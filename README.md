# Radha Birthday Website

A purple-themed birthday microsite made with plain HTML, CSS and JavaScript.

## Run
1. Keep `index.html`, `style.css`, and `script.js` together.
2. Keep both supplied photos in the `assets` folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Optional music
Add a royalty-free or otherwise authorised MP3 at `assets/birthday-music.mp3`. The site works without music. Browsers may block autoplay until the visitor taps the music control or opens the surprise.
